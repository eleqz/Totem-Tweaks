## Features
#### _General Features_
- Changing totem size for handheld
- Changing the totem pop size
- Disable Equip Animation of the totem
#### _Totem Pop Animation_
- Option to Disable the pop animation
- Configurable Totem Pop Animation Speed
- Lock Rotation Position (Locks the position of the totem during rotation)
- Disable Rotations (Disable all totem rotations)
- Static Size (Keeps the totem at its largest size during the animation)
#### _Size Animation_
- Lets a handheld totem grow and shrink, with a configurable speed and size range

## Supported Versions
| Loader   | Minecraft     |
|----------|---------------|
| Fabric   | 1.19 - 26.3   |
| NeoForge | 1.20.4 - 26.3 |

Fabric needs [Fabric API](https://modrinth.com/mod/fabric-api). To change the settings in game, install
[YetAnotherConfigLib](https://modrinth.com/mod/yacl) or [Cloth Config](https://modrinth.com/mod/cloth-config) and
open them with `/totemTweaks`, from [Mod Menu](https://modrinth.com/mod/modmenu) or from NeoForge's mod list.
YetAnotherConfigLib is used when both are installed. Without either, the settings are in `config/totemtweaks.json`.
`/simulatePop` previews the pop animation.
